# Research workbench 1.1

The offline explorer can collect, export and restore unverified observations for an exact evidence snapshot. Imports from a different snapshot or files claiming accepted review are rejected atomically. The Disc explorer adds readable descriptive measures, selectable comparison scenarios and source-hashed scenario downloads.

This package includes the immutable Git correction tracker, which needs a repository checkout with history. It also preserves Linear B's authenticated historical replay repair when used in that project.

Download `research-workbench.zip`, verify its SHA-256 against `research-workbench.zip.sha256`, extract it and open `workbench/evidence.html`. Notes are not saved automatically: download before closing.

Engineering release only. Native versions, corpus readings, rights and scientific acceptance gates are unchanged. Existing release tags and assets remain immutable.
