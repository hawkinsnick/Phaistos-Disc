# Pre-epigrapher engineering ceiling

The project intentionally separates engineering completeness from independent epigraphic acceptance.

## Automated layers now expected to be green
- deterministic native-corpus/source-ledger replay
- source and witness accounting
- apparatus and declared sensitivity scenarios
- source-coverage and occurrence ledgers
- descriptive research suite and negative-result boundaries
- Aegean interchange/family readiness
- evidence and edition workbenches
- immutable correction tracking
- rights/provenance plumbing audit
- adversarial human-review acceptance tests
- AI bundle synchronization and acceptance-state guardrails

Run `python scripts/reproduce_all.py` for the deterministic local stack and `python scripts/audit_rights_provenance.py` for declared rights/provenance plumbing. CI separately reacquires the byte-pinned public-domain primary source and runs browser integration tests.

## Deliberately blocked
No software milestone may manufacture independent review, physical-object inspection, reviewer identity/expertise/independence, adequate physical evidence, phonetic values, language identification, sign equivalence, or decipherment. Final 2.0 remains conditional on the recorded human-review acceptance mechanism.

## Future reviewer insertion point
A reviewer can work without code using `reviews/INDEPENDENT-REVIEW-HANDOFF.md`. Returned evidence enters through `research/review-ingestion-runbook.md`; the exact accepted packet is hash-pinned, then the existing acceptance report propagates the resulting state through validation and AI-facing claims.
