# Family contract 1.1

Phaistos Disc is added as a fifth native corpus member. The interchange project enum accepts `phaistos-disc`. No other native evidence, scientific result, or blocked gate is promoted by this extension. Previously frozen four-member baselines and pilot reports retain their original scope and content versions.

Phaistos Disc 0.1.0 contains one editorial object scaffold with two faces, 45 Unicode base sign types and a separate combining mark, and zero checked transcription/occurrence records. Its actual impression count remains unknown in this release. Faces do not create independent documents. Membership implies no linguistic relationship, shared native sign identifiers or pooled analysis.

All five members run the contract, version, rights/provenance and evidence integrity checks locally and in CI. These certify software and contract integrity, not epigraphic accuracy. Transcription acquisition is the Disc's next native gate.
