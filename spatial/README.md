# Source-figure coordinates

These are approximate manually placed group-region anchors in Evans 1909 numbered drawings. They are normalized to the entire historical page. The exact original PDF digest and one-based page index identify each frame; rendering resolution does not alter normalized coordinates.

Anchors support figure navigation and visual review. They are not stamp centroids, physical millimetres, a modern photograph registration or synthetic spiral positions. Every native occurrence retains null physical coordinates. No spiral geometry, orientation angle or starting point is manufactured.

Source label/order and project traversal remain separate. Image assets are generated from the pinned PDF and included in versioned release bundles; `fetch_primary_sources.py --render` reproduces source pages for a Git checkout. The declared 0.03 uncertainty is an approximate navigation tolerance, not a measured confidence interval.
